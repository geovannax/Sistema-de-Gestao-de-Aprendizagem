Bem-vindo à documentação oficial do Sistema de Gestão de Aprendizagem!

Este projeto é uma plataforma completa para gerenciamento de atividades, grupos, contas de usuários e muito mais, construída com Django e Docker, pronta para ambientes de desenvolvimento e produção.

---

## Visão Geral

O sistema é composto por múltiplos aplicativos (apps) Django, cada um responsável por uma parte da solução:

- **accounts**: Gerenciamento de usuários e autenticação
- **activity**: Criação e controle de atividades e exercícios
- **group**: Organização de grupos de usuários
- **common**: Funcionalidades e utilitários compartilhados
- **core**: Configurações principais do projeto

O deploy pode ser feito localmente ou via Docker Compose, com suporte a PostgreSQL, Redis e Nginx para produção.
